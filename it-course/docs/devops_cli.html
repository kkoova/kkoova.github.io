TERMINAL_INTERFACE_BASICS

Цель: Полный отказ от GUI (интерфейса мыши) для управления ОС.

01_CONCEPT

Терминал (CLI) — прямой способ общения с ядром системы.
Путь в Linux начинается с корня / или домашней папки пользователя ~.

02_LIVE_CODING_GUIDE

Шаг 1: Навигация
pwd — Узнать текущий путь.
ls -la — Показать все файлы (включая скрытые).
cd Documents — Перейти в папку.
Шаг 2: Манипуляция данными
mkdir PROJ_X — Создать папку.
touch config.tmp — Создать пустой файл.
cp config.tmp backup.tmp — Копировать файл.
mv backup.tmp old_config.tmp — Переименовать/Переместить.
Шаг 3: Массовые операции (Automation)
mkdir test_{1..10} — Создать 10 папок одной командой.
rm -rf test_* — Удалить все папки, начинающиеся на "test".
ВНИМАНИЕ: Команда RM стирает файлы навсегда. Корзины не существует.

03_INDEPENDENT_QUEST: "LOST_DATA"

Вводные: Данные проекта были перемещены вредоносным скриптом.
Локация: ~/LABYRINTH
Алгоритм поиска:
  1. Войти в начальный сектор: cd ~/LABYRINTH.
  2. Искать файл-подсказку. Помните: хакеры скрывают файлы (используйте -a).
  3. Прочитать содержимое подсказки: cat .hint.txt.
  4. Следовать по указанному пути. Найти файл core_v04.bin.
  5. Эвакуировать файл: переместить его в корень домашней папки и переименовать в final_result.py.

04_PRO_SKILLS

TAB — Автодополнение (начни писать имя файла и нажми TAB).
↑ / ↓ — История команд (не пиши одно и то же дважды).
Ctrl + C — Прервать любую застрявшую команду.
