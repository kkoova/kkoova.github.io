PHASE_01 // THE_X_RAY

РЕНТГЕНОВСКОЕ ЗРЕНИЕ

Любой сайт — это просто набор текста. Мы можем видеть его насквозь.

1. Открой любую страницу (например, google.com)
2. Нажми F12 или CTRL+SHIFT+I
3. Выбери иконку стрелочки в левом верхнем углу панели (Inspector)
4. Наведи на любой текст на сайте и кликни.
PHASE_02 // REALITY_EDIT

ИЗМЕНЕНИЕ РЕАЛЬНОСТИ

Ты можешь временно изменить любой сайт на своем экране.

1. Найди через инспектор заголовок на странице
2. В окне кода нажми по тексту дважды
3. Напиши свое имя и нажми Enter.

ФОКУС: Измени баланс на своей карте в онлайн-банке (визуально!) или текст новости.
Нет, изменения только в твоем браузере. После обновления страницы (F5) всё вернется обратно. Но это помогает понять, как хакеры делают фейковые скриншоты.
PHASE_03 // HIDDEN_DATA

ЗАДАНИЕ 1: ПОИСК ФЛАГА

Программисты часто оставляют секреты в комментариях кода.

1. Открой страницу нашего курса (где колесо)
2. Используй F12, чтобы найти в коде HTML комментарий вида <!-- FLAG_... -->
3. Скопируй найденный код.
PHASE_04 // BYPASS_LOCK

ЗАДАНИЕ 2: ВЗЛОМ КНОПКИ

Иногда кнопка "заблокирована" (серая), но это всего лишь одно свойство в коде.

1. Найди на странице "секретную" серую кнопку (преподаватель скажет где)
2. Через инспектор найди в её коде слово disabled
3. Удали это слово прямо в коде и нажми Enter
4. Кнопка стала активной? Жми на неё!
