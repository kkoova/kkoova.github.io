PHASE_01 // TERMINAL_IDENTITY

СОЗДАНИЕ ПРОЕКСТА И УСТАНОВКА ЛИЧНОСТИ

Эту часть нельзя сделать только кнопками. Git должен знать автора.

0. Открывает VS Code
1. Open Folder + создайте на рабочем столе папку с любым названием
2. Создай файл index.html (new file) и попробуй туда вписать данный код (добавь <> для h1):
h1 Привет, это твоя тестовая страница! /h1
3. Для проверки результата нажми по файлу index.html правой кнопкой мыши и выбери Open in Brouser

Посмотри что получилось

Это просто небольшой код для написание веб-страничек. Подробнее мы разребем его позже.

Теперь время передать Git кто мы:
1. Terminal -> New Terminal и вписываем:
git config --global user.name "Your Name"
git config --global user.email "mail@example.com"
PHASE_02 // GUI_WORKFLOW

ВИЗУАЛЬНЫЙ КОММИТ (VS CODE)

Открой папку проекта в VS Code. Используй вкладку "Source Control" (иконка ветвления).

1. Нажми кнопку "Initialize Repository"
2. Файл у нас уже создан, и он должен появитсья во вкладке ниже: "Changes"
3. Теперь напиши сообщение, что обозначает изменения, или что было сделанно
4. Нажми "Commit" (Снизу появиться история репозитория)
5. Изменим как то файл, и добавим новый + снова делаем коментарий и комит. Посмотри что получилось

Пока все наши изменения храняться на компьютере, то есть локально, пршло время перенести все в облако.

1. Нажми кнопку "Publish Branch" (войдите или создайте аккаунт на GitHub)
2. Задай ему имя: "work_01_01" и выбери public (все могут видеть все файлы)
3. Зайдите на страницу проекта, осмотритесь
Слева в VS Code третья иконка сверху (выглядит как три точки, соединенные линиями). Это твой пульт управления гитом.

PHASE_04 // START_TERMINAL

СОЗДАТЬ ЛОКАЛЬНЫЙ РЕПОЗИТОРИЙ С ПОМОЩЬЮ ТЕРМИНАЛА

Превращаем обычную папку в "умную", без помощи интерфейса.

1. Откройте новый проект 2. Задайте ему корневую папку (Назовите ее например "WORK_01")
Теперь пробуем работать с терминалом, запоминать данные команды не обязательно, но при проблеммах с интерфесом и иных ошибках комита, работа в терминале может спасти целый проект.
PHASE_05 // INITIALIZATION_TERMINAL

СОЗДАТЬ ЛОКАЛЬНЫЙ РЕПОЗИТОРИЙ

Превращаем обычную папку в "умную" - с записью истории.

mkdir IT_JOURNAL
cd IT_JOURNAL
git init
В папке появилась скрытая директория .git. Теперь система следит за каждым твоим символом.
PHASE_03 // SNAPSHOT

СДЕЛАТЬ ПЕРВЫЙ СНИМОК (COMMIT)

Сохраняем состояние файлов.

Создайте файл README.md
git add README.md
git commit -m "feat: initial commit"
ADD — это подготовка (выставили людей для фото). COMMIT — это щелчок затвора (сохранили момент навсегда).
PHASE_04 // CLOUD_SYNC

ОТПРАВИТЬ В ОБЛАКО (GITHUB)

Твой код теперь доступен всему миру (и учителю).

git remote add origin [ССЫЛКА_ИЗ_GITHUB]
git branch -M main
git push -u origin main
