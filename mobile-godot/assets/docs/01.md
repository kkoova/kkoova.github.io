# Проект №1: "Digital ID Card" — Интерактивная визитка
**Цель:** Ознакомиться с интерфейсом Godot 4, системой узлов (Nodes), контейнерами UI и базовым синтаксисом GDScript.

---

## Часть 1: Подготовка проекта (Настройка под Mobile)

1.  **Создание проекта:**
    *   Запусти Godot, нажми **+ New Project**.
    *   Назови его `DigitalCard_Project`.
    *   Выбери Renderer: **Compatibility** (это важно для мобильных устройств и старых видеокарт).
2.  **Настройка экрана:**
    *   Перейди в `Project -> Project Settings -> Display -> Window`.
    *   **Viewport Width:** 1080, **Viewport Height:** 1920 (стандарт 9:16).
    *   **Stretch Mode:** `canvas_items` (чтобы UI масштабировался).
    *   **Aspect:** `expand`.
    *   **Handheld -> Orientation:** `Portrait`.
3.  **Эмуляция тача:**
    *   В поиске настроек введи `touch`. В разделе `Input Devices -> Pointing` включи **Emulate Touch From Mouse**. Теперь клики мышки Godot будет считать за касания экрана.

---

## Часть 2: Построение интерфейса (UI)

В Godot для UI используются «зеленые» узлы (**Control**). Главное правило: **никогда не расставляй элементы вручную на глаз**, используй контейнеры.

1.  **Главный узел:** Создай корневую сцену типа **User Interface** (узел `Control`). Назови его `Main`.
    *   В верхней панели нажми «Layout» (Якоря) и выбери **Full Rect**. Теперь наше приложение занимает весь экран.
2.  **Задний фон:** Добавь в `Main` узел `ColorRect`. Назови его `Background`.
    *   Тоже выстави ему **Full Rect**.
    *   Выбери приятный темный цвет в инспекторе.
3.  **Основной контейнер:** Добавь в `Main` узел `MarginContainer`.
    *   Выстави **Full Rect**.
    *   В инспекторе (раздел `Theme Overrides -> Constants`) поставь отступы (margin) со всех сторон по 50 пикселей. Это "безопасная зона", чтобы текст не прилипал к краям экрана.
4.  **Вертикальная стопка:** Внутри `MarginContainer` добавь `VBoxContainer`.
    *   Этот узел будет автоматически выстраивать элементы один под другим.
    *   В его настройках (`Theme Overrides -> Constants`) поставь **Separation: 40**.

**Наполняем контентом (внутри VBoxContainer):**
*   **Аватарка:** Добавь `TextureRect`. Назови `Avatar`.
    *   В поле `Texture` перетащи любую картинку (можешь использовать стандартную иконку Godot `icon.svg`).
    *   Включи `Expand Mode: Ignore` и `Stretch Mode: Keep Aspect Centered`.
    *   Выставь `Custom Minimum Size` (например, Y = 400).
*   **Текст (Имя):** Добавь `Label`. Назови `NameLabel`.
    *   Напиши там своё имя.
    *   В `Horizontal Alignment` выбери **Center**.
*   **Текст (Профессия):** Добавь ещё один `Label`. Назови `JobLabel`.
    *   Напиши "Студент / Разработчик".
*   **Кнопки:** Добавь `HBoxContainer` (горизонтальный ряд кнопок).
    *   Внутри него добавь две кнопки (`Button`). Назови их `DevButton` и `DesignButton`.
    *   Напиши на них "Dev Mode" и "Design Mode".
    *   У обеих кнопок в `Size Flags` поставь **Horizontal: Expand**, чтобы они делили место поровну.

## Часть 3: Стилизация (Themes)

Чтобы приложение выглядело профессионально, создадим общую тему.

1.  Выбери корневой узел `Main`.
2.  В инспекторе найди поле **Theme** и нажми `[Empty] -> New Theme`.
3.  Нажми на созданную тему. Откроется нижняя панель.
4.  Здесь можно перетащить файл шрифта (`.ttf` или `.otf`) в раздел "Default Font", и **все** надписи в приложении изменятся сразу.
5.  Там же можно настроить стиль кнопок (скругление углов, цвета при нажатии).

## Часть 4: Программирование (GDScript)

Пришло время вдохнуть жизнь. При нажатии на кнопки мы будем менять данные на карточке.

1.  Нажми правой кнопкой на узел `Main` -> **Attach Script**.
2.  Сотри всё лишнее. Напишем логику:

```gdscript
extends Control

# Ссылаемся на узлы UI через @onready (они подгрузятся при старте)
@onready var name_label = $MarginContainer/VBoxContainer/NameLabel
@onready var job_label = $MarginContainer/VBoxContainer/JobLabel
@onready var background = $Background
@onready var avatar = $MarginContainer/VBoxContainer/Avatar

# База данных наших "состояний"
var profiles = {
	"dev": {
		"name": "Алексей Разработчик",
		"job": "Godot Engine Expert",
		"color": Color("#2d3436")
	},
	"design": {
		"name": "Алекс Дизайнер",
		"job": "UI/UX & Motion Design",
		"color": Color("#6c5ce7")
	}
}

func _ready():
	# Установим начальное состояние
	update_ui("dev")

func update_ui(profile_key: String):
	var data = profiles[profile_key]
	
	name_label.text = data["name"]
	job_label.text = data["job"]
	
	# Плавная смена цвета фона (Tween)
	var tween = create_tween()
	tween.tween_property(background, "color", data["color"], 0.4).set_trans(Tween.TRANS_SINE)
	
	# Небольшая анимация "подпрыгивания" аватарки
	var bounce = create_tween()
	bounce.tween_property(avatar, "scale", Vector2(1.1, 1.1), 0.1)
	bounce.tween_property(avatar, "scale", Vector2(1.0, 1.0), 0.1)
```

## Часть 5: Сигналы (Связь интерфейса и кода)

Теперь нужно, чтобы кнопки вызывали функцию `update_ui`.

1.  В дереве узлов выбери `DevButton`.
2.  Перейди во вкладку **Node** (рядом с Inspector).
3.  Дважды кликни на сигнал `pressed()`.
4.  В появившемся окне выбери наш скрипт на узле `Main` и нажми **Connect**.
5.  Godot создаст функцию `_on_dev_button_pressed()`. Напиши в ней:
    ```gdscript
    func _on_dev_button_pressed():
        update_ui("dev")
    ```
6.  Повтори то же самое для `DesignButton`, передав в функцию строку `"design"`.

## Часть 6: Запуск и проверка

1.  Нажми **F5** (или иконку Play вверху). Godot попросит выбрать главную сцену — выбирай `Main.tscn`.
2.  Покликай по кнопкам. Цвет фона должен меняться плавно, текст — мгновенно, а иконка — слегка пульсировать.

### Советы преподавателю:
*   **Акцент на контейнерах:** Студенты будут пытаться растягивать `Label` мышкой. Объясни, что на мобилках тысячи разных разрешений (от узких Sony до квадратных Fold), и только контейнеры спасут их от "поехавшей" верстки.
*   **Tween-анимации:** Это "киллер-фича" Godot. Покажи, как одной строчкой кода `create_tween()` можно сделать интерфейс живым. Это вызывает у студентов восторг.
*   **Типизация:** Если студенты сильные (знают Java/C#), приучай их сразу писать `var data: Dictionary` или `func update_ui(key: String) -> void:`. Это хорошая практика.
